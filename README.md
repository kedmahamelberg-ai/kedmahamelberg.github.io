# kedmahamelberg.github.io

A lightweight legacy entry point for Kedma Hamelberg’s public web presence.

## Role in the portfolio

The site preserves a stable, discoverable route to work on applied AI, digital behaviour and human impact.

**Academic value:** it supports open, public-facing research communication alongside project repositories and scholarly outputs.

**Impact beyond academia:** it makes research identity and project pathways easier for collaborators, students, practitioners and wider audiences to find.

Current work is available at [kedmahamelberg.com](https://kedmahamelberg.com/) and [Hamelberg AI](https://hamelberg-ai.com/).
